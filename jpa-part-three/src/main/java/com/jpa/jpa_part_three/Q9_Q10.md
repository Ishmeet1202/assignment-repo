## Q9) Which method on the `session` object can be used to remove an object from the cache?

### Answer

The method on the Hibernate Session object used to remove a specific entity from the first-level cache (Persistence Context) is:

```java
session.evict(entity);
```
---

## Q10)  What does `@transactional` annotation do ?

### Answer

The `@Transactional` annotation in the Spring Framework is a declarative transaction management tool.
It allows developers to define the scope of a database transaction directly on a method or a class
without writing boilerplate code to manually start, commit, or roll back transactions.

### Example code

```java
@Transactional
public void transferMoney(Account from, Account to, double amount) {
    withdraw(from, amount);
    deposit(to, amount);
}
```
We can focus on the business logic and not need to write boilerplate code for each and every transaction.
